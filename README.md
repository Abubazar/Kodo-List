Kodo List

Kodo List is a simple to-do list web app I made. It's basic, but unique.

Unlike a traditional to-do list, Kodo List uses a node tree system where you add tasks as bubbles and connect them to one another in a tree-like structure. This comes in handy when dealing with easy-to-complex tasks or tasks that need to be completed progressively.

Getting Started

You can either go straight to the "Kodo List live page" (https://kodo-list.netlify.app) or run it locally on your computer.

To run it locally, download or clone this repository onto your computer.

Make sure Python is installed, or use another method of running a localhost server.

Running Locally

Open the project folder in CMD or your terminal and run:

python -m http.server 8000

Then open the following address in your browser:

http://localhost:8000

Usage

Using this app is super simple.

To add a new task, click the New Task button. A dialog will pop up where you can type in your task. Press Enter to confirm, and a new task bubble will appear on the canvas.

You can connect bubbles by dragging from the right hook of one bubble to the left hook of another. This creates a child relationship between the tasks.

Multiple bubbles can be connected as you wish.

You can click and drag a bubble to move it around the canvas.

To mark a task as complete, select the bubble and use the menu on the left. You can edit its content, delete it, or mark it as completed. Marking a task as complete will add a strikethrough to its text.
